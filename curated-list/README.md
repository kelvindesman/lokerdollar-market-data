## What "verified" means

Every row below passed two independent checks before being included — nothing
here is a raw, unfiltered scrape:

1. **Geo-eligibility** — the posting's full text was analyzed to confirm the
   employer does not restrict the role to a specific country or region that
   would exclude an Indonesia-based applicant. A listing worded "remote" but
   scoped to a single foreign country (or a neighbouring region) is excluded
   even though a keyword match alone would have let it through.
2. **Freshness** — reconfirmed still open within the last few days, either
   because it was newly posted or because the listing was independently
   re-checked at its original source and found still live. A listing we can
   no longer confirm is dropped, not guessed at.

Only roles that pass **both** checks, posted in the last 7 days, appear
in the table below. This file refreshes every day, so a role that goes stale
or gets filled simply drops off the next run.
